# GuildDing

A tiny World of Warcraft Forever addon that automatically announces level-ups in guild chat with the fixed name **René**, regardless of which character levels.

Example:

```text
[René] Ding! Level 15!
```

## Installation

1. Download the repository ZIP and extract it.
2. Place `GuildDing.toc` and `GuildDing.lua` together in `World of Warcraft/_forever_/Interface/AddOns/GuildDing/` (adjust the game folder for your installation).
3. Restart WoW or reload the interface. Confirm **GuildDing** is enabled on the AddOns screen.

The addon only sends a message when you level up while in a guild. There are no settings or dependencies.

## Compatibility

TOC interface number: `16001` (WoW Forever). If the game labels it out of date, confirm the current interface number on your client.
